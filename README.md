# Bank AI Compliance Assistant

**银行 AI 应用合规风险智能评估助手**是一个 Python + Streamlit 项目。它把业务事实映射为可解释的风险规则，逐条展示风险维度、固定分值、事实判断、法律或监管依据与整改建议，并支持导出中文 HTML 完整报告、CSV 风险明细和英文 PDF 摘要。可选接入 DeepSeek API，将已命中的去标识化规则结果整理为 P0/P1/P2 整改计划；DeepSeek 不参与评分。

> **仅供模拟评估、面试演示和内部初筛；不构成法律意见、监管结论或上线审批依据。**
>
> 规则仅反映截至 **2026-11-10** 核验的部分公开法规要求。具体适用性取决于业务场景、主体角色、数据分类分级、数据流向、服务对象及服务范围，应由法务、合规、数据安全等专业人员结合最新规则复核。

## 快速运行

要求 Python 3.10 或更高版本。以下命令适用于 Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器打开 `http://localhost:8501`。如果不希望激活虚拟环境，也可以直接运行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

样例、规则计算与三类报告导出均在本地完成，不配置密钥也可完整演示。只有用户主动开启“DeepSeek API”并点击生成时才会联网调用；API Key 不写入项目文件或报告。

### 可选：启用 DeepSeek API

推荐在 PowerShell 会话中设置环境变量，避免把密钥写入代码：

```powershell
$env:DEEPSEEK_API_KEY="你的 DeepSeek API Key"
python -m streamlit run app.py
```

也可以在页面左侧的密码输入框临时输入。项目使用 DeepSeek 官方 OpenAI 兼容端点 `https://api.deepseek.com/chat/completions`，默认模型为 `deepseek-flash`，也可选择 `deepseek-v4-pro`。模型名称与接口已按 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/quick_start/agent_integrations/) 于 2026-11-10 核验。

调用时只发送风险分数、规则 ID、风险维度、规则生成的事实摘要、法源与控制建议；**不会发送项目名称、自由文本场景描述、客户原始数据或页面中的真实提示词**。在银行真实环境中仍应先完成供应商、数据出境、合同和信息安全评审。

## 3 分钟演示路径

1. **0:00—0:30｜定位与边界**：指出页面顶端免责声明，说明工具用于上线前初筛，不能替代法务判断或审批。
2. **0:30—1:15｜高风险案例**：加载“智能信贷预审助手”，展示第三方境外 API、可识别客户信息、自动化授信建议等业务事实，以及由这些事实触发的极高风险结果。
3. **1:15—2:00｜可解释规则**：展开风险明细，任选“自动化决策”“跨境数据处理”“PIPIA”三条，说明每分都能追溯到固定规则、事实判断与条件化法源提示，不存在黑箱模型。
4. **2:00—2:30｜治理闭环**：展示数据字段白名单、脱敏隔离、人工复核与一票否决、供应商合同控制、RAG 引用与幻觉拦截、公平性测试、解释申诉等整改建议；如已配置密钥，可演示 DeepSeek 把命中规则整理成 P0/P1/P2 计划。
5. **2:30—3:00｜对比与交付**：切换“内部合规知识问答助手”说明风险随数据流和服务范围变化；下载 HTML、CSV 和英文 PDF 摘要。

## 透明评分逻辑

引擎只做确定性的规则加分：`总分 = 所有已触发规则的固定分值之和`。17 条规则的最高分合计为 100，不使用机器学习、概率预测、隐藏系数或二次权重。

| 规则 | 触发维度 | 分值 |
| --- | --- | ---: |
| R01 | 处理个人金融信息 | 4 |
| R02 | 处理敏感个人信息 | 7 |
| R03 | 向模型输入可识别客户信息 | 7 |
| R04 | 使用个人信息进行自动化决策 | 6 |
| R05 | 影响授信、定价、准入等重大权益 | 9 |
| R06 | 使用第三方大模型或 API | 5 |
| R07 | 存在境外存储、访问或其他跨境处理 | 9 |
| R08 | 重要数据出境及主体属性需核验 | 5 |
| R09 | 重大权益场景缺少人工复核或一票否决 | 8 |
| R10 | 提示词、输出或审批日志存在缺口 | 4 |
| R11 | 法定触发场景下未完成 PIPIA | 8 |
| R12 | 生成内容缺少来源引用或事实核验 | 5 |
| R13 | 自动化决策缺少偏见与公平性测试 | 4 |
| R14 | 缺少客户解释、申诉或更正渠道 | 5 |
| R15 | 缺少字段白名单、脱敏或环境隔离 | 5 |
| R16 | 第三方供应商与合同治理控制不完整 | 5 |
| R17 | 生成式 AI 安全评估/算法备案适用性或落实情况存在缺口 | 4 |

风险等级固定为：

- `0—24`：低风险
- `25—49`：中风险
- `50—74`：高风险
- `75—100`：极高风险

分值是本演示项目的内部初筛尺度，**不是监管机关发布的评分标准**。页面中的完整规则目录可直接核对每条触发条件与分值。

## 覆盖能力

- 个人金融信息与敏感个人信息分开识别；“个人金融信息”不会被当然等同为全部属于敏感个人信息。
- 对自动化决策及授信、定价、准入等重大权益影响分别计分。
- 区分第三方委托处理与向其他个人信息处理者提供的角色判断，不把所有 API 调用机械归入同一法律关系。
- 识别境外处理、重要数据和关键信息基础设施运营者身份的待核验事项。
- 检查人工复核、一票否决、日志、PIPIA、RAG 来源引用、事实核验、红队测试、版本管理、公平性测试及客户权利渠道。
- 检查供应商尽调、数据处理协议、训练禁用、审计权与删除证明等工程和合同控制。
- 所有导出与页面共用同一评估结果，避免“页面一套分、报告另一套分”。

## 报告导出

- **中文 HTML 完整报告**：UTF-8 自包含文件，可在浏览器打开并“打印为 PDF”。
- **CSV 风险明细**：使用 UTF-8 BOM，便于 Excel 直接打开中文内容。
- **英文 PDF 摘要**：使用 ReportLab 在本地生成，包含分数、等级、主要风险、重点整改和免责声明。

导出报告会重复展示免责声明和法律适用性边界。日志治理建议遵循必要性、合法性、脱敏、权限和保存期限控制，不将“全量留存可识别提示词”描述为统一法定义务。

## 法律依据与适用边界

法源核验日期：**2026-11-10**。本项目使用的官方文本包括：

- [《中华人民共和国个人信息保护法》—国家互联网信息办公室（来源：中国人大网）](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)
- [《中华人民共和国数据安全法》—国家互联网信息办公室](https://www.cac.gov.cn/2021-06/11/c_1624994566919140.htm)
- [《生成式人工智能服务管理暂行办法》—国家互联网信息办公室](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)

规则至少涵盖《个人信息保护法》第 6、21、23、24、28—30、38—39、51、55—57 条，《数据安全法》第 31 条，以及《生成式人工智能服务管理暂行办法》第 4、11、17 条。

需要特别注意：

- 《生成式人工智能服务管理暂行办法》依其第 2 条主要适用于利用生成式 AI 技术向境内公众提供服务；企业内部应用未向境内公众提供服务的，不因使用生成式 AI 就当然适用该办法。内部项目可把相关条款作为治理参考，但不应直接得出违法结论。
- 《个人信息保护法》第 21 条的委托处理与第 23 条的向其他个人信息处理者提供，取决于供应商是否自行决定处理目的、方式及真实数据流，应先完成角色识别。
- 《数据安全法》第 31 条针对境内运营中收集、产生的**重要数据**出境，并区分关键信息基础设施运营者与其他处理者；它不是所有数据跨境的一般评估条款。
- 人工复核、一票否决、训练禁用、审计权、删除证明、RAG 引用、幻觉拦截、红队测试、版本与日志管理等属于为实现法定目标而设计的治理措施，不应表述为上述条款逐字列举、对所有项目统一适用的义务。

## 项目亮点

- **业务事实驱动**：先确认场景、主体、数据流和服务范围，再提示可能适用的要求。
- **100% 可解释**：规则 ID、触发条件、固定分值、事实判断、法源和整改建议均可审计。
- **治理而非只报风险**：把风险直接落到数据、模型、供应商、流程和客户权利五类控制。
- **演示稳定**：核心评分与三类导出无账号、无外部 API 依赖，可一键加载高低风险样例；DeepSeek 仅为可选增强。
- **AI增强可控**：DeepSeek 仅归纳去标识化的规则结果，不参与评分；未配置密钥时自动保持纯本地演示。
- **交付友好**：中文页面与完整报告适合内部评审，英文 PDF 摘要便于跨团队沟通。
